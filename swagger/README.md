# Swagger — Clothica API

Документація REST API проєкту **Clothica**, створена на основі **OpenAPI 3.0.3** і доступна через Swagger UI.

## Запуск

1. Встановіть залежності: `npm install`.
2. Запустіть бекенд: `npm run dev`.
3. Відкрийте **http://localhost:4000/api-docs**.

## Структура

- `swagger/openapi.yaml` — опис ендпоінтів, параметрів, запитів і відповідей.
- `src/server.js` — підключення Swagger UI до Express за адресою `/api-docs`.

## Оновлення документації

Після змін маршрутів, Joi-валідації або формату відповідей оновіть `swagger/openapi.yaml`. Перезапустіть сервер (`rs` у nodemon) і оновіть сторінку Swagger UI.

> **Примітка:** більшість контролерів ще розробляються. Частина схем запитів і відповідей у Swagger має попередній характер та потребує узгодження з командою. Swagger документує API, але не реалізує його функціональність.
